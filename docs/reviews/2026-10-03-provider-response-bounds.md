# Provider response and quote-input bounds

Workplan PR57. The three app API transports share a streaming JSON reader: 2MiB decoded body, at most4096 entries per array, depth64, string length65536 and numeric strings80 characters before any domain conversion. Exceeding a limit rejects the response with an explicit error; existing failover/degradation preserves the error and never truncates data into a complete-looking snapshot. Request-owned cancellation also cancels the body reader. Quotes reject assets over256 characters and amounts over80 characters before regex evaluation, URL construction or fetching.

The largest full body observed during the reviewed PR13 capture was381437-byte Maya nodes; 2MiB gives over5x headroom. Captured fixtures retain only three selected rows and therefore cannot prove maximum supported production size. The4096-row bound gives over11x365-day history; every nested array has the same ceiling. Numeric80 matches existing exact RUNEPool/TOR conversion limits. The 64-level and65536-character bounds are transport safeguards rather than protocol maxima. Widen a limit only with reviewed response evidence and a corresponding bounded-work check.

Content-Length is an early advertised-size check; streamed bytes remain authoritative. An unencoded body with a differing stated length fails. Compressed responses have different wire and decoded lengths, so equality is intentionally skipped for Content-Encoding; decoded bytes remain bounded. UTF-8 decoding is strict. JSON.parse and row/digit checks run only after the byte ceiling; no unbounded response.json fallback remains in these transports. Historical data retains its interval semantics.

Checks reproduce over-row acceptance and unbounded quote requests before the fix, then verify streamed overflow/cancellation, dishonest length, encoded length, nesting/numeric limits, valid zeros and normal parser fixture replay. Existing THORNode deadlines, caller abort, cooldown and failover regressions remain. Local/CI results do not certify upstream response sizes or provider accuracy.
