# THORNode collection timing and delivery evidence

Workplan PR43, based on merged#205 plus the PR10/11 request-cycle/deadline candidates. `LiveDataResult.checkedAt` for the three composite THORNode collectors now records completion. `collection.startedAt` records cycle start, `completedAt` records completion, `durationMs` uses the monotonic clock, and `blockObservedAt` records when the selected provider latest-block JSON body resolved. Provider/path/height coalescing retains one block-body observation per provider. Exact feature snapshot differences remain separate.

`assessedAt` is delivery/decision time. Reassessment copies data and recomputes block age; it preserves the original observation receipt and only replaces parser-owned freshness details keyed to `block.header.time`. Unknown/unmatched/legacy diagnostics retain their exact metadata for strict validation. Existing degraded/unknown/paused states are never upgraded merely by waiting. Per-source `retrievedAt` is the collection check time, not an independent timestamp for every HTTP body; only the block body has the explicit observation receipt in this change.

Cached readiness returns reassess source ages and `/api/ready` reports its precise decision time. The existing12s warning/30s degradation and negative-age policy remain unchanged. TTL and fresh-block expiry from#205 remain, with an additional monotonic expiry cap so a wall-clock rollback cannot retain the cache longer than10s. Request budgets remain12s overall/5s per request with caller cancellation; no clock synchronization or universal TTL is introduced.

Verification: delayed-body completion and stale/future delivery regressions failed before the timing change; a separate wall-clock rollback regression reproduced prolonged cache retention. Unit checks cover original-receipt preservation, non-mutating copies, unknown diagnostic preservation and existing readiness strict/string compatibility. Local/CI evidence is recorded in the workplan ledger; this does not certify production clock health or provider accuracy.
